# Security

Please report security problems privately, not in a public issue:

- GitHub: **Security → Report a vulnerability** on this repository, or
- email hello@opendocs.cc with "Security" in the subject.

Include what you found, how to reproduce it, and what an attacker could do
with it. We'll reply within a few working days and keep you posted until it's
fixed. Please give us a reasonable time to fix it before publishing details,
and don't access other people's data, run automated scans against
opendocs.cc or disrupt the service while testing.
