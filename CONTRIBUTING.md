# Contributing

Thanks for your interest in OpenDocs.

**Issues are welcome:** bug reports, ideas and questions about the code. For
security problems, see [SECURITY.md](SECURITY.md) instead.

**Pull requests are welcome.** For anything bigger than a small fix, open an
issue first and describe what you'd like to change, so we can agree on it
before you spend time on the code. Contributions are accepted under the
repository's [MIT license](LICENSE).

The same goes for the related repositories:
[opendocs-cli](https://github.com/opendocs-cc/opendocs-cli),
[doc-converter](https://github.com/opendocs-cc/doc-converter),
[opendocs-extension](https://github.com/opendocs-cc/opendocs-extension) and
[skills](https://github.com/opendocs-cc/skills).
