# Contributing

Thanks for your interest in OpenDocs.

**Issues are welcome:** bug reports, ideas and questions about the code. For
security problems, see [SECURITY.md](SECURITY.md) instead.

**Pull requests:** we can't accept outside code contributions to this
repository yet. The code is under the Functional Source License, and taking
contributions needs a contributor agreement we haven't set up. If you'd like
to fix something, open an issue first and describe the fix; we'll make the
change and credit you.

Repositories that are MIT ([opendocs-cli](https://github.com/opendocs-cc/opendocs-cli),
[opendocs-extension](https://github.com/opendocs-cc/opendocs-extension) and
[skills](https://github.com/opendocs-cc/skills)) take pull requests.
